Privacy Policy

Last updated: February 4, 2026

1. Information We Collect

Cyori collects minimal data necessary to provide its services.

  • User Identification: Your Discord User ID is stored to manage per-user settings, playlists, and premium status.
  • Server Information: Guild IDs are stored to remember server-specific configurations.
  • Usage Analytics: We may log command usage to identify bugs and optimize bot performance.

2. How We Use Data

Data is used only for bot functionality and is never sold to third parties.

3. Data Retention & Deletion

Settings are stored while the bot is present. You can request data deletion anytime.

4. Third-Party Integrations

We use YouTube, Spotify, and SoundCloud APIs for streaming.

5. Security Measures

We use industry-standard security to protect your data.
