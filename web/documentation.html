Introduction

Cyori is a high-quality, feature-rich Discord music bot designed to deliver the best audio experience for your community. With support for high-fidelity streaming, advanced audio filters, and a user-friendly dashboard, Cyori stands out as a premium choice for any server.

Key Features

  • Lossless Audio Quality
  • 24/7 Music Playback (Premium)
  • Advanced Audio Filters (Nightcore, Vaporwave, 8D, etc.)
  • Web Dashboard & Lyrics Support
  • Multi-Language Support (English / Thai)

Installation

Inviting Cyori to your server is simple. Just click the link below and authorize the bot.

Invite Bot

Note: The bot requires Connect, Speak, and Read Messages permissions to function correctly.

Initial Setup

After inviting Cyori, you can configure it for your server using the following steps:

  1. Join a voice channel where you want the bot to play music.
  2. Use the /play command to start playing a song.
  3. (Optional) Use /language th to switch the bot's language to Thai.
  4. (Optional) Set a DJ role using /djrole to manage permissions.

Music Commands

Basic commands to control music playback.

Command Description
/play [query/url] Play a song from YouTube, SoundCloud, Spotify, etc.
/pause / /resume Pause or resume the current track.
/skip [index] Skip to the next song or a specific number of songs.
/skipto [index] Skip to a specific song position in the queue.
/stop / /leave Stop playback and leave the voice channel.
/queue / /history Show the current queue or recently played history.
/nowplaying Show details of the currently playing song.
/volume [1-100] Adjust playback volume (Premium can go up to 200%).
/shuffle / /clear Shuffle the queue or clear all songs from it.
/remove [index] Remove a specific song from the queue by its index.
/seek [time] Jump to a specific time in the current song.
/lyrics / /grab Get lyrics or save the current song.
/move [from] [to] Change the position of a song in the queue.
/fix_region Try fixing voice lag by switching regions.

Filter Commands

Enhance your listening experience with real-time audio effects.

Command Description
/nightcore / /vaporwave Apply Nightcore or Vaporwave effects.
/8d / /rotation Apply 8D Audio / Rotation effect.
/speed [0.1-2.0] Change music playback speed.
/karaoke / /distortion Apply Karaoke or Distortion effect.
/lowpass / /tremolo Apply Lowpass or Tremolo effect.
/cleareffect Remove all active audio effects.

FAQ

Why can't I hear any sound?

Make sure you are in a voice channel and the bot has permissions to Speak. Check if you have server deafened yourself or the bot.

How do I get Premium?

You can purchase Premium via our dashboard or by using the /buy command. We offer monthly, yearly, and lifetime (789 THB) plans. Premium gives you access to 24/7 mode, Volume control up to 200%, and exclusive customization.
